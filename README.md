# Melody 相机

> 把喜欢的人，拍成喜欢的样子。

中文 iOS 拍摄陪伴项目：拍前给出能照着做的构图指导，拍后保留原片、自然调色。采用 **SwiftUI + AVFoundation**，领域规则和模型接入独立；不需要 Objective-C。选择依据见 [技术调研](docs/技术调研.md) 和 [选型决定](docs/adr/0001-native-camera.md)。

## 现在可以体验什么

- **进入即取景**：iPhone默认启动后摄，底部中央快门拍照后直接进入当前项目；旁边可以从系统相册选图。
- **一个项目完成整个拍摄过程**：同项目保留多张照片，每张照片可以反复生成推荐并切换历次结果；选模板返回取景，跟拍继续加入该项目。
- **项目详情**：主体自动命名，也可手动改名；照片区分主照片、模板跟拍和补充照片。点大图可全屏缩放，保存按钮写入相册，跟拍照片可叠加当时模板（旧记录可能只有目标框）。
- **本机历史**：原片、推荐批次、编辑配方自动保存；从历史恢复继续编辑。没有云同步，卸载应用会删除本机历史。
- **双模型照片分析**：DeepSeek Flash云端与Gemma 4 E2B手机本地均完成公开样图实测，负责详细观察与摄影建议；在线由选择在线模型后点击生成推荐触发，无额外许可开关。
- **真实主体描边**：Apple Vision在本机分割实际轮廓，等比摆放到目标框，并显示机位示意。尚未合成新的视角轮廓；Qwen 另提供 AI 生成参考图，不是真实新视角重建。
- **手机参考图**：原图与推荐文案交给此 iPhone 内的 Draw Things / Qwen Edit 异步生成，默认 512 × 512，模板可先跟拍；已完成手机真实出图与恢复验证。
- **分级日志**：设置内查看/筛选 Debug、Info、Warning、Error 和模型输入输出，关联生成图，可关闭正文记录或清理；不记录密钥和图片正文。
- **自然调色**：原片保持不变，调色保存副本；每张照片恢复各自配方。Mac版本是练习环境，不能替代手机硬件。

摄影知识驱动的新目标轮廓是后续核心方向，见 [推荐引擎架构](docs/推荐引擎架构.md)。本地知识库入口为 [docs/README](docs/README.md)。

## 启动

```sh
./scripts/run-mac.sh
```

Mac版使用演示画面练习项目流程，也可从底部选择照片；不使用摄像头。iPhone启动即取景，拍照后从项目页生成推荐。

安装完整 Xcode 后：

```sh
./scripts/run-ios.sh
```

模拟器不需要付费账号；自己的 iPhone 可以先用免费 Personal Team，TestFlight 并非必要。详见 [开发环境与真机步骤](docs/开发环境.md)。

## 代码入口

```text
Sources/
  MelodyCore/       # 构图领域、离线规则、模型请求和输出校验
  MelodyImaging/    # 图像解码、缩放、调色与编码
  MelodyApp/        # SwiftUI、拍摄流程、相机、钥匙串、网络传输
Tests/              # Swift Testing：核心、像素处理、应用流程
project.yml         # 可重建的 Xcode 工程配置
MelodyCamera.xcodeproj/
scripts/            # 一键运行和环境检查
```

运行 `swift test` 验证业务行为，`swift build` 编译 Mac 版。iOS 验证须另用 Xcode，不能用 Mac 编译结果代替。

不会自动分析；选择在线模型并点击生成推荐才上传缩略图；不收集账号、不设后台、不自动上传照片。Key 保存在本机钥匙串。历史从本版新增照片开始保存在本机；重要原片仍可单独导出备份，卸载应用会删除本机历史。

### 推荐参考图

当前已在 **此 iPhone 内**通过 Draw Things 开源引擎运行 Qwen Image Edit 2511，原照片与推荐文案一起生成低清构图参照。模板先可用，参考图异步排队生成，失败不阻塞跟拍。全局分辨率默认 512 × 512，可选 512 × 768、768 × 512、768 × 768，每个任务保存提交时的设置。

Mac 中转方案已撤销；旧记录仅作历史，不作为手机生成结果展示。手机端当前实测状态见 [验证记录](docs/验证记录.md) 末节，架构见 [ADR 005](docs/adr/005-iPhone端侧参考图.md)。编译通过不能代替真机出图验收。
