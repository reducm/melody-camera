# Melody 相机

> 把喜欢的人，拍成喜欢的样子。

中文 iOS 拍摄陪伴项目：拍前给出能照着做的构图指导，拍后保留原片、自然调色。采用 **SwiftUI + AVFoundation**，领域规则和模型接入独立；不需要 Objective-C。选择依据见 [技术调研](docs/技术调研.md) 和 [选型决定](docs/adr/0001-native-camera.md)。

## 现在可以体验什么

- **可运行的原生 Mac 练习版**：三种矢量场景、照片导入、三套离线构图方案、九宫格、人物目标轮廓和数字变焦练习。
- **在线视觉接入**：配置支持图像的 Chat Completions 兼容接口、模型 ID 与 Key；显式允许上传后分析，返回经过校验的方案。尚未使用真实服务商 Key 验收。
- **照片处理**：自然、暖调、胶片调色，强度、原片对比、原片/副本导出。不是磨皮或生成式修脸。
- **iOS 原生源码与 Xcode 工程**：后摄取景、拍照、按设备能力显示倍率、顺序多倍率采样、相册保存。当前机器没有 Xcode，iOS 编译和真机能力仍待验证。

本地 Gemma、实时姿态对齐、连拍选片、睁眼修复在后续规划中。离线规则没有冒充本地大模型，人物框是目标位置而非人体检测结果。

## 启动

```sh
./scripts/run-mac.sh
```

进入界面点“给我拍摄灵感”，选一张方案卡，然后点快门进入调色。导入照片按钮在取景上方。Mac 版不使用摄像头。

安装完整 Xcode 后：

```sh
./scripts/run-ios.sh
```

模拟器不需要付费账号；自己的 iPhone 可以先用免费 Personal Team，TestFlight 并非必要。详见 [开发环境与真机步骤](docs/开发环境.md)。

## 代码入口

```text
Sources/
  MelodyCore/       # 构图领域、离线规则、模型请求和输出校验
  MelodyImaging/    # 图像解码、缩放、调色与编码
  MelodyApp/        # SwiftUI、拍摄流程、相机、钥匙串、网络传输
Tests/              # Swift Testing：核心、像素处理、应用流程
project.yml         # 可重建的 Xcode 工程配置
MelodyCamera.xcodeproj/
scripts/            # 一键运行和环境检查
```

运行 `swift test` 验证业务行为，`swift build` 编译 Mac 版。iOS 验证须另用 Xcode，不能用 Mac 编译结果代替。

默认离线；只有主动允许并触发在线分析才上传缩略图；不收集账号、不设后台、不自动上传照片。Key 保存在本机钥匙串。关闭应用前请导出想保留的照片，首版不持久化拍摄历史。
