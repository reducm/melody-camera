<a id="p01"></a>
## P01 相机取景

**一级工作面 · 已实现**

打开就能拍摄第一张，或在当前项目继续补拍。

**入口**：启动；P03 重新拍摄；P14 新建后的空项目。

**页面结构**

1. 顶部：历史／项目名称／新建／设置
2. 中部：后摄竖向 3:4 取景与九宫格开关
3. 下方：设备可用倍率
4. 底部：选照片／中央快门／当前项目或历史

**动作与去向**

| 用户动作或结果 | 去向 |
|---|---|
| 拍照成功 | [P03 项目工作区](#p03) |
| 选照片 | [P02 系统照片选择](#p02) |
| 当前项目 | [P03 项目工作区](#p03) |
| 拍摄历史 | [P14 拍摄历史](#p14) |
| 设置 | [P15 设置](#p15) |

**状态与异常**

- 无项目：拍第一张才建立项目
- 有项目：新照片加入当前项目
- 相机准备或拍摄中：显示阶段，防重复点击
- 相机不可用：说明状态，可重试相机或选图

**行为规则**

- 仅后摄竖屏；倍率按设备能力过滤
- 照片不自动上传，也不自动生成推荐
- 相机权限由系统请求；本稿不复刻系统弹窗

**数据**：成功后保存原始文件、来源、实际倍率；保留当前项目。

**已有证据与待验**：历史有用户确认拍照与 0.5/1/2 硬件倍率检查；本轮仅核对源码。连续拍摄、方向和中断待真机验收。

**验收条件**：A01、A02、A04、A12、A18。未授权相机时不能展示可拍的假画面。

**待讨论**：Q05：跟拍前是否需要更简洁的引导文案？

**源码入口**：[StudioView.swift](../../Sources/MelodyApp/StudioView.swift)

**界面图**：[P01 相机取景公开照片示意](assets/camera-photo.png)。公开咖啡样图代替相机取景。Rachel Michetti / CC0；不表示相机已启动。

## P02 系统照片选择

**系统界面 · 已实现**

选择一张已有照片加入当前项目。

**入口**：P01 或 P03 的选照片按钮。

**页面结构**

1. 系统 PhotosPicker：照片列表与系统选择操作
2. 返回应用后：读取数据并导入
3. 导入成功：项目展示照片并在本机提取轮廓

**动作与去向**

| 用户动作或结果 | 去向 |
|---|---|
| 选定并导入成功 | [P03 项目工作区](#p03) |
| 取消，返回原入口 | [P01 相机取景](#p01) |
| 读取失败 | [P21 错误与恢复提示](#p21) |

**状态与异常**

- 用户取消：返回原入口，项目不变
- 读取 iCloud 图片：等待系统数据
- 失败：提示等待下载后重试，不创建残缺照片
- 成功：追加照片，旧照片保留

**行为规则**

- P03 发起的取消应返回 P03；线框按钮只演示来自 P01 的路径
- 只接收用户所选图片，不扫描私人相册
- 导入不触发在线分析

**数据**：保留选中原始字节；导入来源；该照片独立配方。

**已有证据与待验**：公开图片真实解码、导入和保存流程已验；系统选择器实际点选尚未完整点测。

**验收条件**：A02、A04、A05。取消不新增照片，错误不覆盖原片。

**待讨论**：是否后续支持一次选多张？当前只有单图导入。

**源码入口**：[ProjectViews.swift](../../Sources/MelodyApp/ProjectViews.swift)

**界面图**：[P02 系统照片选择模拟器截图](assets/p02-photo-picker.png)。系统 PhotosPicker 实际界面；可见公开测试图与模拟器预置素材。未执行选图导入。

## P03 项目工作区

**一级工作面 · 已实现**

以当前照片串起推荐、跟拍、调色和历史。

**入口**：拍照、导入成功；P14 恢复项目；P11 换模板或拍照返回。

**页面结构**

1. 顶部：项目标题与手动改名、照片数量、保存状态
2. 照片带：序号与主照片／模板跟拍／导入／补拍标签
3. 当前大图：全屏、保存菜单、跟拍模板叠加
4. 页内切换：推荐与模板／编辑照片
5. 底部：重新拍摄／选照片／生成推荐或再生成一轮

**动作与去向**

| 用户动作或结果 | 去向 |
|---|---|
| 主体与推荐设置 | [P04 主体与推荐设置](#p04) |
| 主动生成推荐 | [P05 分析进行中](#p05) |
| 查看当前推荐 | [P06 照片分析报告](#p06) |
| 编辑照片 | [P12 编辑照片](#p12) |
| 点大图 | [P13 项目照片全屏](#p13) |
| 重新拍摄 | [P01 相机取景](#p01) |
| 选照片 | [P02 系统照片选择](#p02) |
| 点击标题 | [P20 修改项目名称](#p20) |

**状态与异常**

- 无推荐：解释从这张照片寻找下一张拍法
- 有推荐：批次菜单切换旧结果
- 照片切换：恢复独立配方和批次
- 项目保存失败：显示重试保存，新建入口禁用

**行为规则**

- 页内分区不是独立页面跳转
- 忙碌时阻止切图/重入；离开项目取消当前分析
- 重拍或导入都保留旧照片；只有新建切换项目

**数据**：项目 activePhotoID、每照片 selectedBatchID、编辑配方、来源标签。

**已有证据与待验**：公开照片多轮推荐/配方/历史恢复已验；长列表与全部 UI 点击待验。

**验收条件**：A02、A04、A07、A13、A16、A18。失败生成不覆盖旧批次。

**待讨论**：Q01：维持单页，还是把报告和模板拆开？

**源码入口**：[PhotoEditor.swift](../../Sources/MelodyApp/PhotoEditor.swift)

**界面图**：[P03 项目工作区模拟器截图](assets/p03-project.png)。公开咖啡测试项目；两张照片及四轮推荐来自既有固定场景/快门夹具，不是真实模型和跟拍结果。

## P04 主体与推荐设置

**项目内区域 · 已实现**

确认要拍谁，并选择下一轮分析方式和拍摄风格。

**入口**：P03 推荐与模板区域；导入或恢复后可查看主体轮廓。

**页面结构**

1. 分析方式：在线／本机 Gemma；模型设置入口
2. 数据目的地提示与参考图运行位置
3. 四种风格：自然纪实／环境叙事／简洁留白／主体质感
4. 主体轮廓：当前原片与真实分割叠加
5. 多主体选择与重新提取

**动作与去向**

| 用户动作或结果 | 去向 |
|---|---|
| 主动生成推荐 | [P05 分析进行中](#p05) |
| 模型设置 | [P15 设置](#p15) |
| 返回项目概览 | [P03 项目工作区](#p03) |

**状态与异常**

- 正在本机提取：显示不确定进度
- 多个主体：用户选择一个用于下一轮
- 无可靠轮廓：明确说明，可继续分析
- 演示画面：单独标非实拍

**行为规则**

- Apple Vision 分割与模型照片观察是不同步骤
- 改变风格和主体不重写已有推荐
- 拍摄风格不等于调色风格

**数据**：所选轮廓 ID 与本机风格偏好；生成时形成输入快照。

**已有证据与待验**：四风格/类别矩阵有自动化证据。公开样本 Mac 6/7 有轮廓，模拟器 0/7 有轮廓；降级通过不代表分割成功。

**验收条件**：A04、A05、A07。无轮廓不能捏造识别成功。

**待讨论**：Q03：未安装本机模型时，方式选择如何提示更清楚？

**源码入口**：[PhotoEditor.swift](../../Sources/MelodyApp/PhotoEditor.swift)

**界面图**：[P04 主体与推荐设置模拟器截图](assets/p04-analysis-settings.png)。推荐设置与主体轮廓区域；来自公开咖啡测试项目，当前轮廓不可用的降级状态真实保留。

## P05 分析进行中

**项目内状态 · 已实现，统一进度待做**

让用户知道当前任务，并能取消。

**入口**：用户点击生成推荐或再生成一轮。

**页面结构**

1. 原照片与已存在的推荐仍可见
2. 底部真实阶段：分析照片／检索摄影知识并计算构图
3. 不确定进度条与取消按钮
4. 冲突操作暂时禁用

**动作与去向**

| 用户动作或结果 | 去向 |
|---|---|
| 成功新增批次 | [P06 照片分析报告](#p06) |
| 取消，保留旧结果 | [P03 项目工作区](#p03) |
| 配置或分析失败 | [P21 错误与恢复提示](#p21) |

**状态与异常**

- 配置校验失败：发送前终止
- Gemma 等待模型资源：不假称采样
- 成功：验证输出再持久保存新批次
- 取消/超时/非法结果：旧批次保留

**行为规则**

- 在线只有本次主动生成才上传压缩图
- 无回调不能给整体假百分比
- 项目/照片来源校验防止迟到结果串图
- 取消、离开或后台后不显示过期响应

**数据**：项目/照片/轮廓/风格快照、调用编号；成功才产生新批次。

**已有证据与待验**：取消、校验与流程有测试；新版 DeepSeek/Gemma scene 合约尚无真调用验收。

**验收条件**：A03、A04、A06、A07、A18。错误不生成成功空批次。

**待讨论**：F01：统一阶段文案；外部 API 不报进度时保留等待状态。

**源码入口**：[StudioModel.swift](../../Sources/MelodyApp/StudioModel.swift)

## P06 照片分析报告

**项目内区域 · 已实现**

理解当前照片的问题和优先动作，再挑选拍法。

**入口**：分析成功；切换照片或历次推荐。

**页面结构**

1. 历次推荐：批次与时间选择
2. 主体名称、概述、优先动作
3. 折叠详情：光线／构图／背景／姿态／成像／判断边界
4. 模型来源与知识规则版本
5. 下方模板列表

**动作与去向**

| 用户动作或结果 | 去向 |
|---|---|
| 查看模板 | [P07 推荐模板卡](#p07) |
| 再生成一轮 | [P05 分析进行中](#p05) |
| 切回项目照片 | [P03 项目工作区](#p03) |

**状态与异常**

- 旧批次：展示当时内容与来源
- 新批次：新增而不是覆盖
- 旧格式无结构化观察：明确保守降级
- 模型观察有未知项：保留判断边界

**行为规则**

- 文字是模型观察，不是客观测量或审美评分
- 名称仅在用户未自定义时自动更新
- UI 不执行模型代码或任意图形

**数据**：不可变 RecommendationBatch、时间、来源、报告和方案。

**已有证据与待验**：批次恢复、非法响应与结构测试已验；实际建议质量仍待样本审核。

**验收条件**：A06、A07、A16。切批次后来源、文案和模板一致。

**待讨论**：Q01：默认只显示优先动作，保留详细分析折叠？当前已是折叠详情。

**源码入口**：[PhotoEditor.swift](../../Sources/MelodyApp/PhotoEditor.swift)

**界面图**：[P06 照片分析报告模拟器截图](assets/p06-report.png)。实际展开的照片分析区域；正文为明确标注的固定测试数据，并非真实模型识别结果。

## P07 推荐模板卡

**项目内重复组件 · 已实现**

选择一套现场能执行的机位和构图。

**入口**：P06 下方 1–3 个模板。

**页面结构**

1. 标题与建议倍率
2. 目标范围／轮廓与机位预览，说明来源
3. 动作、理由、有顺序的步骤
4. 摄影依据与适用条件折叠区
5. AI 参考图附件与按这个模板拍摄

**动作与去向**

| 用户动作或结果 | 去向 |
|---|---|
| 按这个模板拍摄 | [P11 模板跟拍取景](#p11) |
| 查看参考图状态 | [P08 参考图任务卡](#p08) |
| 回看报告 | [P06 照片分析报告](#p06) |

**状态与异常**

- 原片轮廓等比摆位
- 有限类别几何设计
- 仅目标范围
- 采用用户核对后的生成图轮廓

**行为规则**

- 不凑三张重复方案；不保证跨轮不同
- 新机位示意不等于重建不可见表面
- 应用相机失败时留在项目；无参考图也可跟拍
- 采用新轮廓时同步更新动作，不能保留矛盾的左右/距离提示

**数据**：ShotPlan 与 CompositionDesign；来源批次、技巧、风格、几何和步骤。

**已有证据与待验**：知识推荐和采用轮廓后文案一致性已回归；真实摄影效果未验。

**验收条件**：A07、A08、A11、A12。文案、目标、来源必须一致。

**待讨论**：Q05：模板卡优先展示一个动作还是全部步骤？

**源码入口**：[PhotoEditor.swift](../../Sources/MelodyApp/PhotoEditor.swift)

## P08 参考图任务卡

**模板内异步组件 · 已实现**

在继续跟拍的同时，查看手机生成的构图参照。

**入口**：P07；开启自动参考图时推荐成功后入队，也可单项生成/重试。

**页面结构**

1. AI 拍法参考图及此 iPhone 运行位置
2. 排队／加载／实际采样进度／解码保存状态
3. 完成后的合成图预览
4. 取消／重试／重新生成／核对轮廓
5. 仅供角度构图参考的说明

**动作与去向**

| 用户动作或结果 | 去向 |
|---|---|
| 放大参考图 | [P09 AI 参考图大图](#p09) |
| 有完整候选时核对 | [P10 核对设计轮廓](#p10) |
| 继续用模板拍 | [P11 模板跟拍取景](#p11) |
| 参考图设置 | [P17 手机模型与参考图设置](#p17) |
| 返回模板 | [P07 推荐模板卡](#p07) |

**状态与异常**

- 关闭：说明到设置开启，模板仍可用
- 排队与加载：真实阶段，无假百分比
- 采样：实际步数百分比，仅覆盖采样
- 完成：已落盘图片；可核对或无轮廓降级
- 失败/取消/中断：保留原片与模板，可重试

**行为规则**

- 默认 512 方图；新尺寸只影响新任务
- 生成不是实拍，不替换原片
- 旧 Mac 作业不混作当前手机结果
- 单任务错误不清空整个推荐批次

**数据**：project/photo/batch/plan/job 关联与提交时尺寸；图像和作业本机持久化。

**已有证据与待验**：旧版真机 512 方图出图/恢复通过；最新图到轮廓链路、其他尺寸与资源压力待验。

**验收条件**：A08、A09、A10、A18。采样 100% 不提前显示生成完成。

## P21 错误与恢复提示

**共用弹窗及原位状态 · 已实现，恢复入口可改进**

**入口**：相机、导入、分析、安装、保存或恢复失败。

**页面结构**

1. 通用标题：暂时没能完成
2. 受控中文错误原因

4. 项目保存失败另有常驻提示与重试保存

- 无权限：说明对应系统权限
- 配置/模型缺失：说明缺少项
- 网络/校验失败：不展示原始敏感响应

**待讨论**：建议按错误类型提供明确恢复动作，需要另行实现。
