## L02 分析与推荐

成功新增批次；失败和取消保留旧结果。没有可靠轮廓仍可生成保守方案。

```mermaid
flowchart TD
    input["P04 主体与推荐设置"]
    run["P05 分析进行中"]
    error["P21 错误与恢复提示"]
    report["P06 照片分析报告"]
    setting["P15 设置"]
    plan["P07 推荐模板卡"]
    old["P03 项目工作区"]
    input -->|"主动生成并校验配置"| run
    run -->|"配置／网络／输出失败"| error
    run -->|"合法观察＋本机知识推荐"| report
    report -->|"展示 1–3 个方案"| plan
    error -->|"关闭后手动去设置"| setting
    setting -->|"完成后重新选择"| input
    run -->|"取消，旧结果保留"| old
    report -->|"切换照片或批次"| old
```

## L03 参考图与新轮廓

任何等待、失败或无法提取，都保留原模板；采用与撤回只影响以后跟拍。

```mermaid
    plan -->|"无需等待"| follow
    job -->|"图片保存完成"| image
    job -->|"有合法完整候选"| review
```


## L06 异常恢复与取消

错误返回原操作，不固定跳首页。后台或取消后拒收旧响应；保存失败有原位重试。

```mermaid

    camera["P01 相机取景"]
    analysis["P05 分析进行中"]
    error["P21 错误与恢复提示"]
    draft["P08 参考图任务卡"]
    import["P02 系统照片选择"]
    project["P03 项目工作区"]
    settings["P15 设置"]
    camera -->|"相机不可用"| error
    error -->|"关闭后仍可选图"| import
    import -->|"导入成功"| project
    analysis -->|"分析失败"| error
    analysis -->|"取消保留旧批次"| project
    error -->|"配置缺失后手动修复"| settings
    draft -->|"图失败仍可用模板"| project
    project -->|"保存失败提示重试"| error
    settings -->|"返回后主动再试"| project
```
