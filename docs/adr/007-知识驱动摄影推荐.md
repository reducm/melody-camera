# ADR 007：知识规则驱动推荐与受控设计轮廓

调研开始：2026-10-03；开发交接：2026-10-04。状态：采用，开发分支实现待构建验证。

## 问题

旧推荐由视觉模型直接给目标框，原片描边只移动和缩放；Qwen 图片与取景模板没有连接。用户要求根据主体、画面和风格给出实际摄影更有用的方案，并允许在独立分支完成调研和实现，之后再 build。

## 决策

1. 保留 Gemma/在线视觉承担观察，新增受控 SceneEvidence；不把摄影正文的关键词拼凑成“已识别事实”。
2. 自建版本化摄影知识卡及纯 Swift 构图规划器，先硬条件过滤，再排序与参数搜索。知识来自已查阅的一手资料的自写摘要，保留出处和限制。当前规模无需 SQL 或向量服务。
3. 同视角保留真实轮廓摆位，新机位采用有限类别几何或明确的范围示意。新轮廓必须带来源，不能将旧描边冒充透视重建。
4. Qwen 生成图再经过本机分割与 3:4 完整性检查；由用户核对后选用。生成成功与主体/角度正确分开，不用模型自评分代替确认。
5. 跟拍保存实际方案快照，保留旧数据兼容；模型 SDK 和像素分割留在适配模块。
6. 本轮不训练新视觉模型，不下载来源权限未明确的摄影作品库。后续先积累有许可、有动作和偏好标注的评估样本，再决定轻量排序模型的收益。

## 代价与验证

知识卡需要维护；模型观察错误仍会影响检索；参数化体块精度有限；几何代价不能证明美学更优。生成图分割增加一个本机阶段，性能与 UI 均须后续设备验收。

按用户要求本轮只做源码与静态检查，测试先写但延后执行。完整来源、算法、数据兼容和验证步骤见 [调研](../摄影知识与推荐模型调研.md) 与 [实现文档](../知识推荐引擎实现.md)。
