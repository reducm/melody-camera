# ADR 004：推荐参考图与本地生成服务

> 2026-10-03 方向纠正：手机通过 Mac 生成并非用户目标，现已撤销这条默认产品路径。本文中的 Mac 部署/出图数据仅为历史实验；当前决策以 [ADR 005：iPhone 端侧参考图](005-iPhone端侧参考图.md) 为准。

日期：2026-10-03。状态：接口与异步交互继续采用；Mac 执行端已由 ADR 005 替代。以下部署行为均为历史，不是当前手机配置。

## 决策

文字推荐 / 受控模板先完成，参考图作为每个推荐项独立的异步附件。参考图失败、排队或取消不禁用模板跟拍，也不把合成图添加为项目实拍。生成图注明“AI 生成参考 · 非实拍”。

首个适配器：iPhone → 用户配置的局域网 Mac 作业服务 → 官方独立 Draw Things CLI → Qwen-Image-Edit-2511。这是 Mac 本地生成，不是 iPhone 端侧；模型不打包进 iOS。选择此路线是为了隔离相机 / Gemma 与大型图像模型的内存和生命周期，并验证编辑质量。

## 接口与边界

- `MelodyCore.ReferenceImageGenerating` 接受已绑定 project/photo/batch/plan 的请求、去定位 JPEG 和进度回调，返回图像字节；不依赖模型 SDK 或网络框架。
- `ReferenceGenerationController` 保存每次作业、关联 ID、来源、状态和独立图片；不修改项目原片。中断重启后显示可重试状态，迟到结果不能覆盖取消。
- `ReferenceImageClient` 实现提交 / 轮询 / 取图 / 取消。校验 ID、进度、文本长度、响应大小，拒绝重定向。生成结果校验尺寸并重新编码，去掉外部元数据。
- Python 作业服务每次只运行一个 CLI，限制队列 / 输入 / 输出 / 运行时间；每次调用强制 `--local --offline --no-download-missing`，不能隐式转云端。CLI 不链接进 App。
- 未来改图 API 使用另一协议实现。供应商鉴权留在具体适配层；Core、推荐关联、卡片状态和拍摄流程不改变。正式增加第二家供应商时，应将服务来源从当前固定文案改成能力描述对象。

## 交互

用户在模型设置中开启参考图并配置目标 Mac。生成新一轮推荐后，各推荐项进入独立队列；既有推荐可单独补图。卡片提供取消、重试、重新生成及放大查看。每轮推荐保留各自结果，不串到其他照片。

只有服务确实报告采样步数时才显示百分比。排队、模型加载、编码与解码显示具体阶段；采样 100% 不代表整个流程结束。不得用计时器伪造整体进度。App 切到后台会取消活动任务；前台拍摄 / 查看其他项目不会等待参考图完成。

## 隐私、部署与后续

默认关闭；用户开启后，主动点击生成才发送压缩图。服务使用随机连接密钥，iPhone 保存在钥匙串；Mac 文件仅当前用户可读。默认监听回环地址，手机测试显式绑定局域网地址。HTTP 仅用于可信局域网原型，不能端口映射到公网；正式分发改用 HTTPS 与可撤销设备配对。

不记录照片、提示词或 CLI 原始输出。作业完成 / 取消清除输入和提示词；结果保留供手机下载，终态记录在 24 小时后随后续作业清理。服务重启清理遗留输入，手机保留已下载结果；当前服务不承诺后台恢复。

Qwen 2511 普通底模以 384×512、20 步作为对照；默认快速分支使用官方匹配的 Edit 2511 Lightning LoRA，4 步、CFG 1、shift 3。下载与真实运行分别验证；性能以实测为准。Multiple-Angles LoRA、主体一致性与角度遵循评估为后续独立实验。参考图提取出的轮廓只能标为“设计轮廓”，不能冒充原片真实分割。
