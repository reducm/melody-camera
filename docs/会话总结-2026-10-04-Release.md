## 实现

- 修复首次远程 CI 的 LiteRT-LM Android LFS 缺失对象：全流程 `GIT_LFS_SKIP_SMUDGE=1`，iOS XCFramework 仍正常下载并由 SwiftPM 校验。
- 固定标准 macOS 26 arm64 runner、Xcode 26.6、锁文件与构建并发，加入依赖缓存和合理超时。
- 新增手动触发 Release 工作流：先测试，再分开构建设备和模拟器 Release，核对产物后创建预发布。默认草稿，可显式公开；已存在的 Release 不覆盖。
- IPA 不含个人签名，模拟器包只支持 arm64。附项目源码、SHA-256、构建来源 JSON 和第三方许可归档，不包含模型或 API Key。
- 共享工程移除个人 Team/Bundle ID 覆盖，XcodeGen 引用公共 xcconfig；现有个人值保存到忽略的 `Config/Local.xcconfig`。没有复制证书、钥匙串或描述文件。
- 根 LICENSE、第三方声明与构建说明已加入；打包检查 33 个依赖 revision，收集 70 份已跟踪许可证/NOTICE。
