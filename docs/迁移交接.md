## 新 MacBook 的接手步骤

1. 解压 ZIP，在解压后的外层目录执行 `shasum -a 256 -c 迁移文件清单.sha256`，应全部显示 OK。
2. 如需保留 Git 历史，在外层目录执行：

   ```sh
   git clone melody-camera-history.bundle melody-camera-dev
   ditto melody-camera melody-camera-dev
   cd melody-camera-dev
   git remote remove origin
   git status --short
   ```

   克隆恢复历史，覆盖复制保留本次最新交接文档；状态应显示文档变化，不要重置掉它们。删除的是指向本地 bundle 的 origin，不涉及远程服务。也可以直接使用 `melody-camera/` 源码目录，但它不含 `.git`。
3. 用 Codex 打开你实际选择的项目目录，先让它阅读 AGENTS.md 与本文。任何命令都以该项目目录为工作目录，不使用旧电脑绝对路径。
4. 用户从 Apple 官方渠道安装适配新电脑 macOS 与目标 iPhone 系统的完整 Xcode，首次打开完成安装与系统提示。版本兼容性请在新机器按 [Apple 官方支持表](https://developer.apple.com/support/xcode/) 核对；旧文档中的版本只是历史记录。无需先购买开发者会员或使用 TestFlight。
5. 在 Xcode 设置的 Locations 中选好 Command Line Tools，安装所需的一套 iOS Simulator，运行下面的验证命令。

```sh
./scripts/check-environment.sh
xcodebuild -version
xcodebuild -showsdks
xcrun simctl list devices available
swift test
swift build
xcodebuild -project MelodyCamera.xcodeproj -scheme MelodyCamera \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath DerivedData CODE_SIGNING_ALLOWED=NO build
./scripts/run-ios.sh
```

`run-ios.sh` 会在发现 XcodeGen 时重生成工程，所以修改个人签名配置时须同步考虑 project.yml。它只打开工程和模拟器，仍需在 Xcode 选择设备并运行，不代表已经完成构建验收。真实模型 Key 需要在新机器重新输入，选择在线模型后点击生成推荐才上传，不设额外开关。
