# 公开照片与模拟器回归

2026-10-04 新增。脚本不扫描相册，不读取真实模型凭据，不向在线模型传图。照片下载到忽略的 artifacts；版本管理只保存来源、许可、SHA-256、测试输入和复现脚本。

## 样本与验证含义

[来源清单](../scripts/public-photo-fixtures.json) 包含 7 张公开照片：NASA 人像、灰度摄影者、猫、咖啡、夜间火箭、玻璃可乐瓶和山地风景。

- 人像、摄影者、猫、咖啡与火箭取自 [scikit-image 官方样图库](https://scikit-image.org/docs/0.25.x/api/skimage.data.html)，各自许可和作者见清单。
- 玻璃瓶来自 [Nicereddy / Wikimedia Commons，CC0](https://commons.wikimedia.org/wiki/File:Coca-Cola_Bottle.jpeg)。它带有源元数据，测试确认编辑副本不继承 GPS，原片字节仍保留。
- 风景来自 [US FWS / Wikimedia Commons，公有领域](https://commons.wikimedia.org/wiki/File:Summer_landscape_in_mountains.jpg)。

每张照片运行实际 ImageIO 解码、Core Image 编辑、Vision 分割、知识规则、项目存储和恢复。场景类别等由清单提供**固定测试夹具**，HTTPS 请求被内存 transport 截获，快门使用 `CameraOperating` 替身。测试不验证模型是否正确认出物体，不证明真实新视角或摄影审美提升；`outlines == 0` 加明确降级说明仅证明失败处理正常。

覆盖四种摄影风格、四轮推荐独立保存、四种调色导出、原片字节一致、GPS 剥离、损坏文件不覆盖旧照片、画廊独立读取、改名和配方恢复、0.5/1/2 倍率保留模板、跟拍方案快照、缺乏手机生图能力时保留模板。参考图成功、审核门槛、撤回、重试隔离与取消使用现有单元测试的受控 provider，不能宣称本轮实际 Qwen 出图。

## Mac 运行

```sh
python3 scripts/prepare-public-photo-fixtures.py artifacts/public-photo-regression/photos
MELODY_PUBLIC_PHOTOS="$PWD/artifacts/public-photo-regression/photos" \
MELODY_PUBLIC_RESULTS="$PWD/artifacts/public-photo-regression/mac-results" \
swift test
swift build
```

没有显式 `MELODY_PUBLIC_PHOTOS` 时该集成测试标记跳过；两个真实模型/单图集成入口同样显式跳过，避免把未运行算作通过。结果逐样本写入 `result.json`，带 `completed`、`passed`、分割情况及逐项检查；照片建议 JSON 另存文件。中途中断不会写成 completed。

## 模拟器运行

先按 project.yml 生成工程并构建 Debug 包：

```sh
xcodegen generate
xcodebuild -project MelodyCamera.xcodeproj -scheme MelodyCamera \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath DerivedData -disableAutomaticPackageResolution \
  ARCHS=arm64 ONLY_ACTIVE_ARCH=YES CODE_SIGNING_ALLOWED=NO build
scripts/run-public-photo-regression.sh <已启动模拟器UUID> \
  DerivedData/Build/Products/Debug-iphonesimulator/MelodyCamera.app \
  artifacts/public-photo-regression/simulator-authorized grant
scripts/run-public-photo-regression.sh <同一模拟器UUID> \
  DerivedData/Build/Products/Debug-iphonesimulator/MelodyCamera.app \
  artifacts/public-photo-regression/simulator-denied revoke
```

脚本只安装到明确指定的模拟器，不卸载应用；公开样图与隔离项目位于 Documents/PublicPhotoFixtures 和 PublicPhotoResults。启动参数 `--melody-check-public-photos` 仅存在于 Debug 模拟器分支，普通启动不跑回归。首次样本额外执行真实 `saveToPhotos` 的原片/副本写入或拒绝分支；没有预置相册权限时不会等待无人值守弹窗，此时结果中没有相册项，不能报告相册通过。

`grant/revoke` 只控制该模拟器内 Melody 的 `photos-add` 权限，测试允许分支会向模拟器相册写入两张公开样图。拒绝分支结束后，可执行 `xcrun simctl privacy <模拟器UUID> grant photos-add com.melody.camera` 恢复人工测试条件。程序内检查不代替 PhotosPicker 点选、权限弹窗点击、分页/缩放/下拉手势或真机硬件验证。

## 本轮结果

详见 [2026-10-04 会话总结](会话总结-2026-10-04.md) 和 [验证记录](验证记录.md)。Mac 7 张中 6 张提取到轮廓，风景无可靠主体；iOS 26.5 模拟器 7 张均走分割失败降级。没有用 Mac 轮廓注入模拟器冒充它成功识别。真实手机分割与模型表现继续按真机样本验收。
